# RZD Live Tracker

Готовое к запуску веб-приложение для отслеживания движения поездов РЖД на
интерактивной карте. Приложение показывает железнодорожные маршруты, станции,
расчетное положение поездов в реальном времени и позволяет искать рейсы между
станциями.

## Возможности

- интерактивная карта Leaflet/OpenStreetMap с линиями маршрутов;
- маркеры станций и расчетные live-маркеры поездов;
- поиск маршрутов между станциями с подсветкой выбранного коридора;
- карточки поездов с номером, брендом, временем в пути, расстоянием и остановками;
- встроенный каталог популярных маршрутов для мгновенного запуска;
- серверный endpoint `/api/rzd/search` для запроса неофициального API `pass.rzd.ru`
  по station code, без CORS-проблем на клиенте;
- zero-build запуск: нужен только Python 3.

## Быстрый старт

```bash
python3 server.py
```

Откройте <http://127.0.0.1:8000>.

Порт можно изменить переменной окружения:

```bash
PORT=8080 python3 server.py
```

## Структура

```text
.
├── app/
│   ├── data/routes.json   # станции и маршруты
│   ├── main.js            # карта, поиск, live-позиции
```

## Источники данных

Основной режим использует встроенный каталог маршрутов, чтобы приложение
работало сразу после запуска. Для поиска реального расписания сервер обращается
к неофициальному endpoint РЖД:

```text
https://pass.rzd.ru/timetable/public/
```

Поиск РЖД может быть недоступен из-за сетевых ограничений, rate limiting,
изменений внутреннего API или необходимости более длительного ожидания RID. В
таком случае интерфейс остается полностью работоспособным на встроенных данных.

Live-proxy включен по умолчанию. Его можно отключить, если нужен полностью
автономный режим:

```bash
RZD_LIVE_PROXY=0 python3 server.py
```

## API

- `GET /api/routes` — каталог станций и маршрутов.
- `GET /api/rzd/search?origin=2000000&destination=2004000&date=05.05.2026` —
  попытка live-поиска расписания РЖД.

## Технологии

- HTML, CSS, JavaScript modules;
- Leaflet 1.9.4 и OpenStreetMap tiles;
- Python 3 standard library (`http.server`, `urllib`) для запуска и proxy.
